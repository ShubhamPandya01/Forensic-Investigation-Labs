# Forensic Investigation — Lab Portfolio
### Shubham Pandya | Post-Graduate Certificate in Cybersecurity, Durham College

## About
These labs simulate real-world digital evidence acquisition and investigation 
techniques used by forensic professionals. Each lab focuses on a different aspect 
of digital forensics including deleted file recovery, memory analysis, Windows 
registry examination, email investigation and file header analysis. Tools used 
vary by lab and are documented within each report.

## Labs
| Lab | Topic |
|-----|-------|
| Lab 1 | File Header Analysis and Autopsy Installation |
| Lab 2 | File Hashing, Data Integrity and Steganography |
| Lab 3 | Deleted File Recovery and FTK Imager Disk Imaging |
| Lab 4 | Photo Evidence Recovery and Altered File Header Detection |
| Lab 5 | Full Forensic Case Investigation |
| Lab 6 | Windows Registry Forensics and Artifact Collection |
| Lab 7 | Memory Forensics and RAM Capture using Volatility |
| Lab 8 | Email Forensics and Header Analysis |

## Tools Used
Autopsy, FTK Imager, WinHex, Volatility, Registry Viewer, Aid4Mail, HxD Hex Editor
